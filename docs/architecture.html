Architecture: parent graph, shares + weather sub-agents

Three compiled LangGraphs share one Gemini factory. The parent never calls Alpha Vantage or Open-Meteo. Stock and weather work are nested invokes started by parent handoff tools. Each graph keeps its own MessagesState.

End-to-end flow (stock question)

Example user text: IBM latest quote and a short overview. Everything below is one parent invoke. The shares graph runs inside the parent tools node and must finish before the parent model speaks again. CLI and UI both wait until step 16. Weather questions follow the same 16 steps with transfer_to_weather_agent and Open-Meteo instead of Alpha Vantage.

Inner quote/overview/news calls (steps 11–14) can repeat. Each is another Gemini round-trip plus an HTTP call. The parent thread never sees those inner ToolMessages — only the specialist’s last text.

What sits on each thread

Parent and shares graphs both use MessagesState (a list that only appends). They are not the same list.

Three runtime paths

Path A — not about stocks

Example: What is 21 + 21, and what time is it in UTC?

Path B — stocks / shares / tickers

The parent model is instructed to call transfer_to_shares_agent instead of inventing prices.

Path C — weather / forecast / air quality

Same handoff shape as Path B. The parent calls transfer_to_weather_agent. The nested graph geocodes a place name, then hits Open-Meteo (no API key).

Process layers

One Python process. Three networks: Vertex (Gemini), alphavantage.co, open-meteo.com.

Graph wiring (compile-time)

Parent — agent/graph.py

  • Nodes: agent (call_model), tools (ToolNode).
  • Edges: START → agent; tools → agent; agent uses tools_condition (built-in name tools or END).
  • Bound tools from get_tools(): get_current_utc_time, add_numbers, transfer_to_shares_agent, transfer_to_weather_agent.

Shares — agent/shares.py

  • Nodes: shares_agent, shares_tools.
  • tools_condition still returns the string "tools". Compile maps {"tools": "shares_tools", END: END} so there is no missing node named tools.
  • Bound tools from get_shares_tools() only (six Alpha Vantage tools).
  • First call to get_shares_agent() compiles once and reuses the graph.
Parent compile. main / UI lifespan calls build_agent() once. get_llm() loads ADC.

Auth — Gemini needs ADC; weather does not

Gemini: GOOGLE_CLOUD_PROJECT, GOOGLE_CLOUD_LOCATION (default us-central1), GEMINI_MODEL (default gemini-2.5-flash), GOOGLE_GENAI_USE_VERTEXAI=true. Market: ALPHAVANTAGE_API_KEY. Free-tier Alpha Vantage is often 5 calls/minute; Note / Information in JSON is a rate limit, not a broken graph. Weather: Open-Meteo is public; no extra env var.
